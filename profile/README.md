# gunk-dev

Tools for personal use that respect the person using them.

## Principles

- **User First** — Software should serve the person using it, not monetize them.
- **Data Sovereignty** — Your data stays yours. Local-first, no telemetry, no lock-in.
- **Public Source & Reproducible Builds** — All code is open. Builds are reproducible so you can verify what you run.

## Projects

- **[flux](https://github.com/gunk-dev/flux)** — Mobile-first PWA for tracking and executing fitness goals. Workout programs loaded from JSON, weight logging per exercise, and YouTube video embeds for form checks.
- **[balance](https://github.com/gunk-dev/balance)** — Personal health and wellness tracker. Quick tap-to-record interface for 12 metrics (mood, stress, energy, etc.) with offline-first persistence.
- **[reel-life](https://github.com/gunk-dev/reel-life)** — AI-powered chatops for home media servers. Connects Claude to the *arr stack (Sonarr, Radarr, Prowlarr, Overseerr) via Telegram or Google Chat.
- **[vibe](https://github.com/gunk-dev/vibe)** — Ultra-simple, free meditation app for Android. Minimalist timer, meditation bells, no ads or tracking.
